# 🛡️ SIEM Log Analyzer

A Python-based security monitoring tool that simulates SIEM behavior by detecting brute-force attacks and suspicious IP activity.

## Features
- Brute-force detection
- Suspicious IP tracking
- Log parsing automation

## Usage
```bash
python log_analyzer.py logs.txt
```

## Output
Detects:
- Multiple failed login attempts
- Repeated IP activity
